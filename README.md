# Иваныч — калькулятор смет и кабинеты сотрудников

Веб-приложение для ремонтно-отделочной компании: быстрый расчёт смет на замере,
кабинет для каждой роли, договоры и акты с автоподстановкой данных клиента,
управленческая отчётность, отделы дизайна и производства.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # предпросмотр собранной версии
```

Приложение открывается на экране выбора сотрудника — войдите под любой ролью,
чтобы увидеть её кабинет и набор прав.

## Что уже работает

### Калькулятор сметы — главный экран замерщика

* **Габариты вместо калькулятора.** Замерщик вносит длину, ширину, высоту помещения,
  количество дверей и окон — площади пола, стен (за вычетом проёмов), потолка,
  периметр и погонаж откосов считаются автоматически. Объём каждой работы подставляется
  из своей базы расчёта (`пол`, `стены`, `периметр`, `проёмы`, …).
* **Живой итог.** Панель справа пересчитывается на каждое действие: сумма по прайсу,
  наценка, скидка, себестоимость, маржа, рентабельность, стоимость за м², разбивка по помещениям.
* **Три способа добавить работу:** быстрый поиск с добавлением по Enter, каталог по разделам,
  готовый технологический набор.
* **Наборы работ (подсказки).** Цепочки, которые не делаются одна без другой:
  «грунтовка → маяки → штукатурка», «грунтовка → шпаклёвка → ошкуривание → покраска»,
  «грунтовка пола → демпферная лента → маяки → стяжка» и другие. Один клик — вся цепочка
  в смете с посчитанными объёмами.
* **Технологические подсказки.** Приложение проверяет состав сметы и предупреждает:
  штукатурка добавлена без маяков, шпаклёвка без грунтовки, плитка на пол без гидроизоляции.
* **Наценка и скидка** — общие на смету и индивидуальные по строке, ползунками и вводом.
  Видимость каждого блока управляется правами: у замерщика наценку можно скрыть полностью,
  а скидку оставить с персональным лимитом.
* **Согласование.** При превышении лимита сотрудника смета уходит руководителю;
  утверждённая смета блокируется от правок, изменения — через новую версию.

### Роли и кабинеты

| Роль | Что в кабинете |
|---|---|
| Замерщик | свои сметы и объекты, конверсия, памятка по замеру |
| Офис-менеджер | клиенты, сметы, готовые к договору, договоры в подготовке |
| Руководитель отдела | очередь согласований, маржа портфеля, показатели команды |
| Экономист | себестоимость, маржа, сметы с низкой рентабельностью, прайс |
| Бухгалтер | график платежей, оплаты, дебиторка, просрочка |
| Генеральный директор | воронка, динамика, сводка по отделам, деньги |
| Дизайнер / Производство | доски задач с зависимостями между отделами |

Права настраиваются в двух местах: **Роли и доступы** — матрица «роль × право»,
**Сотрудники → 🔐** — персональные исключения поверх роли (выдать или отобрать конкретное право)
и лимиты по скидке и наценке.

### Документы

Данные клиента вводятся один раз в его карточке и подставляются во все документы объекта:
смета → договор → акты выполненных, дополнительных и скрытых работ. Печатные формы
готовы к печати и сохранению в PDF, выгружаются в HTML, отправляются клиенту письмом
с заполненной темой и текстом. У клиента с несколькими договорами документы разделены по объектам.

### Замер на объекте

Бриф-чек-лист из 7 блоков (общее, демонтаж, инженерия, поверхности, санузлы, материалы, итоги),
фотофиксация, загрузка чертежей, **запись голосовых комментариев прямо в приложении**
с полем для расшифровки. По ответам брифа приложение предлагает наборы работ и собирает
черновик сметы кнопкой **«⚡ Собрать смету по брифу»**.

### Прайс

107 позиций в 12 разделах со стоимостью для клиента, себестоимостью, базой расчёта объёма
и технологическими связями. Выгрузка и загрузка через CSV (Excel → «Сохранить как CSV»),
режимы «дополнить» и «заменить целиком».

## Как подключить свой прайс

1. **Прайс → ⬇ Выгрузить CSV** — получите файл с нужной структурой столбцов.
2. Замените строки своими работами и ценами в Excel.
3. **Прайс → ⬆ Загрузить прайс** — выберите файл, проверьте предпросмотр, нажмите «Загрузить».

Обязательные столбцы — «Наименование» и «Цена». Остальные (Раздел, Код, Ед.изм.,
Себестоимость, База расчёта, Коэффициент, Спутники, Обязательные) читаются, если есть.

## Устройство проекта

```
src/
  domain/        типы, права ролей, стартовые данные (прайс, наборы, бриф)
  lib/           расчёты: геометрия помещений, суммы сметы, подсказки, аналитика, документы
  store/         хранилище (localStorage), файлы вложений (IndexedDB), контекст доступа
  components/    общие элементы интерфейса, выбор работ, редактор помещений, доска задач
  pages/         экраны: кабинеты, калькулятор, прайс, документы, администрирование
```

Стек: React 18 + TypeScript + Vite, без тяжёлых зависимостей — приложение лёгкое и быстрое.

## Где сейчас хранятся данные

В браузере устройства (localStorage для базы, IndexedDB для фото и аудио).
Этого достаточно для работы одного сотрудника и для проверки процессов.
Резервная копия и перенос — **Настройки → Выгрузить/Загрузить базу**.

Общая база для всех сотрудников, реальная авторизация, отправка писем с сервера
и расшифровка голосовых комментариев — следующий этап, см. [docs/ROADMAP.md](docs/ROADMAP.md).
